# Security Policy

## Supported Versions

Security fixes are provided for actively supported releases of
GamerXDGZLocatorForMinecraft.

## Reporting a Security Issue

Please report security vulnerabilities privately through
GitHub's security reporting features when available.

Please do not publicly disclose an unpatched vulnerability.

## Security Principles

GamerXDGZLocatorForMinecraft is designed to:

- Be free and open-source
- Avoid unnecessary external network connections
- Avoid collecting personal information
- Avoid storing passwords or authentication tokens
- Minimize dependencies
- Respect Minecraft permissions
- Respect player visibility systems where supported
- Avoid unnecessary server resource usage
- Keep configuration transparent
- Avoid advertisements and telemetry

The plugin does not intentionally include hidden services,
tracking, advertisements, or data collection.

# Changelog

## 1.0.0-dev

### Added
- Player locator system
- Nearby-player detection
- Distance calculation
- Relative direction calculation
- Configurable detection range
- Configurable update interval
- Maximum player display limit
- Same-world filtering
- Locator enable/disable controls
- Permission support
- `/locator info`
- Platform abstraction
- EaglerXServer integration abstraction
- Safe fallback when EaglerXServer is unavailable
- GitHub Actions automated builds
- Security-focused configuration
- MIT open-source licensing

### Compatibility

Currently verified:
- Modern Paper-based Minecraft environment: build compatibility

Not yet verified:
- Minecraft 1.8.8
- Minecraft 1.12.2
- Eaglercraft 1.8.8
- Eaglercraft 1.12.2

These versions will not be advertised as supported until tested.
